# ZUI 0.3.0 本地发布验收

验收开始于 2026-11-10，完成于 2026-11-11（Asia/Shanghai）。发布目标为 yeyouyuan/zui、GitHub Pages 和 GitHub Packages；npmjs 暂缓。

## 已完成

- 工作区 typecheck、lint、单元测试、全部包与文档生产构建通过；版本更新后的 MCP 测试也通过。
- 最终浏览器回归 163/163 通过，耗时 9.1 分钟，零跳过、零不稳定用例。
- 78 个导航页面在 1440px/320px、light/dark 四组环境下共 312 次显示检查通过；检查运行异常、标题、溢出、示例裁切、图片和文字对比度。
- 16 个业务区块在四种宽度、两种主题下检查布局、交互和无障碍。
- 页面编辑器覆盖完整组件目录、模板、多页、响应式设计、拖拽、图层、资源、数据、主组件、变量、交互逻辑、离线导出和备份往返。
- 本地协作覆盖真实文件导入、编辑、评论、版本、备份恢复、下载和存储异常。
- 87 个 registry 条目、251 个生成文件和 71 个 MCP 示例通过消费检查。
- ESM/CommonJS、客户端边界、七个包的打包内容、许可证与 registry 数据检查通过。
- 临时 registry 真实安装七个 GitHub 发布名称，保留 @zui/* 别名；运行 ESM、CommonJS、React 19 SSR、CSS、CLI、MCP stdio 和严格 TypeScript 声明检查。
- 组件 ESM gzip 为 88,153 字节，小于 98,304 字节预算。
- 保留线上 v0.2.0 的 JS、CSS、LICENSE，防止文档站升级破坏旧版 CDN 引用；修复设计资源页在 /zui/ 部署路径下的演示链接。

## 本次复核处理

首轮 161/163 通过。布局检查在画布短暂不可见时直接读取坐标，改为等待有效几何信息；默认业务模板已更换，旧的无障碍检查改用明确的表单、进度和按钮样例，继续检查完整画布与编辑器的 axe 结果。随后独立运行完整回归，163 条全部通过。

一次局部重复检查与组件重建同时运行，导出虚拟模块因重建期间 dist 不完整而返回 500；构建和浏览器回归分开执行后，最终完整回归的导出与离线原型检查通过。CI 同样在所有构建结束后串行运行浏览器用例。

## 范围与限制

页面设计器与内容工作台使用当前浏览器的本地存储，未提供业务后端或多人共享。主组件不能嵌套；跨页主组件/令牌同步需要通过工作区备份完整恢复；页面快照不保存历史主组件注册表；原型切页会重置页面状态。REST 接口仅支持不携带身份凭据的 GET，受浏览器 CORS 约束。

GitHub Packages 的实际可见性由包设置决定，工作流会记录可见性和仓库关联。GitHub registry 安装需要有包读取权限的认证；安装方法见 [GitHub Packages](./GITHUB-PACKAGES.md)。
