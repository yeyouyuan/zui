# OfficeStudio 独立文档编辑器

2026-11-13：独立 `OfficeStudio` 已在基础编辑能力上补齐图片、页眉页脚、查找替换、工作表与行列增删、表格合并与冻结、筛选排序、原生图表、条件格式、数据验证与填充、Excel 字体/字号、超链接和选择性粘贴、PDF 绘图与表单，以及打印和历史版本。可见工具、菜单与表单直接使用 ZUI 的 Button、Input、Select、Tabs、DropdownMenu、ColorPicker、Modal、Checkbox、Radio/RadioGroup、Collapse 和 Table 等组件；Word、Excel、PDF 分别使用自己的文档模型和编辑内核。无需文档服务器，示例没有调用 `/api/office`。

本地页面：`http://127.0.0.1:5175/#/components/office-studio`。已有 `OfficeEditor` 的 ONLYOFFICE 集成继续保留。v0.4.0 包含 73 个 UI 组件与 16 个业务块，两个编辑器均随 `@zui/react` 和 Registry 分发。

本轮依据 ONLYOFFICE web-apps、sdkjs 与 ranuts/document 的固定源码版本调整标题栏、文件菜单、标签、两行工具分组、画布与状态栏；实际来源和 ZUI 映射见 [界面与操作参考记录](office-studio-reference-2026-11-12.md)。已完成本地字体/行高及本轮编辑操作的浏览器核对；真实打印与 Office 精确分页仍需单独验收。功能状态逐项见 [Office 功能细节对照](office-function-comparison-2026-11-12.md)，不能据此认定整体功能已完全一致。

示例导入入口最大 20 MB。Word 单张图片最大 8 MiB，嵌入图片总量最大 25 MiB；查找超过 10,000 处匹配时停止全部替换，并限制替换后的文字总量。Excel 上限为 10,000 行、256 列、32 张工作表和 100,000 个已使用单元格，一次复制粘贴或填充最多 10,000 格，每格输入最多 32,767 个字符；填充生成内容累计最多 5,000,000 个字符。公式使用解析器计算，具有循环引用、依赖深度与计算预算控制，不执行 `eval`；排序会调整支持的相对引用，并拒绝无法保留含义的跨行依赖。筛选为每列单一条件，支持包含、等于、大于和小于。PDF 支持 1–200 页，全文查找要求页面具有可提取文字以及 renderer 提供 `search`。未知或超限结构会提示错误，原文件与当前画布内容保持可恢复。

Word 使用连续文稿和显式分页，没有 Office 的完整自动分页与复杂版式兼容能力。画布中的默认页眉页脚显示在文稿顶部和底部，PAGE/NUMPAGES 显示占位值；导出为原生域后由打开 DOCX 的排版程序计算。PDF 在原页面上叠加新增内容和表单控件；手写签名是笔迹绘图，不是证书数字签名。

Excel 内部复制会冻结单元格、公式计算值、完整直接格式、列宽、完整包含的合并区域和原生超链接快照。开始标签中的“选择性粘贴”及 Ctrl/⌘ + Alt + V 提供全部、仅公式、仅值、仅格式、公式与数字格式、值与数字格式、保留源格式、除边框外全部、仅列宽和转置；公式按实际目标位置调整相对引用，仅值使用复制时结果，转置同步转换链接和合并区域。每次粘贴在全部验证通过后作为一次历史操作提交，失败不保留部分改动。选择性粘贴要求先在当前 OfficeStudio 会话中复制区域；外部应用的纯 TSV 仍按普通粘贴处理。

Excel 内部普通粘贴会根据来源调整相对引用。行列增删会调整当前表与其他表的相对、绝对、矩形及整行整列引用，部分删除时缩小范围，已删除引用变为 `#REF!`；合并、冻结、筛选、图表和原文件的打印范围同步调整。无法安全变换的动态引用、三维或结构化范围会拒绝整次操作。工作表仍被其他表引用时禁止删除，每张表最多记录 500 次行列结构操作，可导出并重新导入后继续；撤销同时恢复结构日志。

Excel 原生超链接使用可选的 `StudioSheet.hyperlinks`，保存单格或矩形范围、外部目标、工作簿内位置、悬停说明与显示文字。修改、新增、删除、重命名、行列结构、排序、复制粘贴及填充会同步链接；以原文件保存和独立 XLSX 导出均写回原生链接及专用关系。带链接的数字、布尔、日期、文字和公式保留真实值类型及公式缓存。未知协议、文件路径、无法解析或超出 UI 范围的目标保留元数据，打开操作只处理当前解析器支持的目标；链接范围可保留完整 Excel A1 地址范围。

`HYPERLINK` 公式保留显示值的标量类型、空引用、错误传播及支持的隐式交叉语义，可靠的顶层调用可形成临时导航记录；`IF` 的引用布尔条件和所选分支引用读取也已修正。旧模型缺少 `hyperlinks` 字段表示尚未读取链接，显式 `[]` 表示清除全部链接；示例在工作区、历史版本和恢复入口进入可写状态前补读原文件，按来源工作表、结构日志和重命名迁移，不再次移动已有显式数组。宿主适配器提供 `hydrateStudioExcelHyperlinks(document, source): Promise<StudioExcelDocument>`，只补缺失字段，不改已有单元格、格式和规则；原文件导出的兼容回退复用同一迁移逻辑。全工作簿链接最多 100,000 条。

条件格式支持 `cellIs` 比较、`expression` 表达式、`containsText` 包含文字、`duplicateValues` 重复值、`uniqueValues` 唯一值、`top10` 前/后若干项或百分比、`aboveAverage` 高于/低于平均值，以及 `colorScale` 二色/三色色阶，共 8 类。规则按优先级合并支持的差异样式，并保留 `stopIfTrue`；差异样式仅覆盖粗体、斜体、下划线、文字/背景颜色和数字格式。色阶仅支持最小值、可选的 50 百分位和最大值；数据条、图标集、标准差、复杂差异样式与其他阈值不在契约内。

数据验证支持 `list` 列表、`whole` 整数、`decimal` 小数、`date` 日期、`time` 时间、`textLength` 文本长度和 `custom` 公式，共 7 类。支持允许空白、输入提示及 `stop`/`warning`/`information` 错误提示；启用错误提示的 `stop` 规则在输入、粘贴或填充时检查完整候选结果，任一目标不符合规则即取消整批。日期和时间规则按 Excel 序号判断，支持的日期/时间输入会规范化。列表使用字面值或同表/跨表的单行或单列来源，最多 1,000 个来源格；字面值列表最多 100 项、总长 255 字符，不支持项内逗号、双引号或控制字符。

`warning` 与 `information` 保留无效输入并标记对应单元格；输入、粘贴、排序及填充等操作汇总实际写入的无效目标数量和首格错误消息。关闭错误消息后保留标记。输入/错误消息支持多行，规则文本在保存前校验 XML 可表示的字符。

日期采用 Excel 1900 日历，包含序号 0 和虚拟闰日 60；DATE、DATEVALUE、DAY、MONTH、YEAR 与日期显示使用一致的边界语义。XLSX 导入保留原始数字日期序号与小数日精度，ISO 日期按 Gregorian 日期转换；重新保存不会因 ExcelJS 的 Date 毫秒转换改变原始数字输入。

每张表的条件格式与数据验证各最多 100 条，各自覆盖格数累计最多 100,000，范围仅为一个矩形 A1 区域，数据验证范围不能重叠。规则公式使用有限的常用 A1 子集；整行整列、结构化、三维、外链、动态和命名引用，以及未知字段或复杂规则会明确拒绝。XLSX 适配按这个契约导入、导出原生规则，不承诺任意 Excel 文件的规则兼容。

向下/向右复制填充分别使用选区最上行/最左列，完整复制输入和直接样式，并调整普通相对公式，绝对引用及公式字符串保持原意。序列支持一个种子或保留两个种子后推导步长，各行/列独立生成；显式步长从末种子继续，直接样式按种子周期继承。数字序列默认递增 1；日期按整数天生成 ISO UTC 日期或 Excel 日期序号；文本保留前缀及尾数宽度，纯数字编号继续保持文本。目标条件格式与数据验证范围保留，含合并区域、不可安全移动的公式、无效种子或超限结果时取消整次填充。

## 界面与字体

公共文件菜单位于标签行左侧，包含新建、打开、保存、导出和打印。Word、Sheet、PDF 使用蓝、绿、红的标题栏主题；标签行 32px、小按钮 24px、工具文字 12px，编辑器底部状态栏为单行 25px。Word 的开始、插入、布局、引用、审阅、视图标签保留现有操作，字体和段落分成两行；样式图库提供正文、无间距、标题 1，并保留其余段落样式菜单。左侧导航切换查找替换、大纲和字数；厘米标尺用于预览，正文使用灰底画布上的白纸。

Word 和 Sheet 的字体组上行使用可编辑的 ZUI Combobox 输入字体和字号；Sheet 下行是粗体、斜体、下划线和文字/填充颜色，段落组使用左、中、右对齐图标。图表仍由独立 SVG 绘制，“查看图表数据”使用 ZUI Collapse 展开 ZUI Table，显示分类和系列值。

| 编辑器 | 缺省字体/字号                  | 菜单范围                                                                                                                                                   |
| ------ | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Word   | 思源黑体（Noto Sans SC）、12pt | 思源黑体、宋体、微软雅黑、Arial、Times New Roman；字号 10、11、12、14、16、18、20、24、28、36、48                                                          |
| Sheet  | Calibri、11pt                  | Calibri、Arial、Aptos、Times New Roman、Courier New、思源黑体、宋体、微软雅黑、等线；字号 8、9、10、11、12、14、16、18、20、22、24、26、28、36、48、72、96 |

两个菜单都补充当前导入的字体名称与字号，包括未列在常用档位的小数字号，也允许键入字体名称和字号。Word 输入接受 1–300pt，并按半磅归一化；Sheet 接受 1–409pt，保留小数。Enter 或选择菜单项提交并回到编辑区，失焦提交时保留目标焦点，Escape 取消草稿；中文输入法组合期间不提前提交，非法值显示错误并阻止保存、导出和打印快照。Word 保留文字选区，Sheet 对整个矩形选区应用格式；切换文档或选区后丢弃过期草稿。实际字形取决于当前系统的可用字体和 CSS 回退，没有枚举全系统字体。旧草稿省略新增 Excel 字体字段时按 UI 缺省值显示，以原始 XLSX 保存仍保留未编辑的原文件字体。

XLSX 适配从原生字体表、单元格和行列样式恢复小数字号，避免 ExcelJS 4.4 的整数解析截断 12.5、14.5 等值。显式单元格样式（包括样式索引 0）优先于行列继承；以原文件保存保留行列字体设置，独立导出写回已建模单元格的有效字体，不展开整张空白网格。只改字号保留字体名称、theme scheme 及其他字体属性；主动改字体名称会解除原 theme scheme，让指定名称生效，其行为对应 sdkjs 的 `setName` 后 `setScheme(null)`。

Sheet 按累计行高计算可见区域、滚动定位、冻结行与合并格跨度，默认 18pt（24px），导入的默认行高、显式行高和手动隐藏行会参与显示。开始标签提供“行高”弹窗（0–409.5pt，0 隐藏）、“自动调整行高”和“恢复默认行高”，应用到选区覆盖的行；双击行号也可自动调整。行高支持撤销重做，并随行列结构编辑、XLSX 保存重开和旧草稿恢复保留。自动调整测量当前字体、字号、换行与列宽，跨多行合并的内容不参与计算；修改字号本身不会自动调整行高。单元格按其边界裁切。Excel 打印使用独立 HTML 表格，沿用当前模型的行高和隐藏行，保留隐藏合并起始行的可见内容；其分页仍由浏览器决定。

PDF 提供开始、批注标签，左导航切换查找、批注、缩略图和表单；查找与缩略图在左面板，批注和表单在右面板，同一导航按钮可关闭面板。页码、前后页、缩放菜单及有界加减位于 25px 状态栏。页面覆盖层中的文字、多行文字、复选、单选和下拉字段分别使用 ZUI Input、Input.Textarea、Checkbox、Radio/RadioGroup 和 Select；查找和标注列表使用 Button。同一字段的单选控件保持受控分组，原坐标、旋转、值提交及只读/禁用行为继续生效。

## Excel 常用编辑补齐

开始标签新增查找/替换、垂直对齐、边框、清除格式和列宽操作。Ctrl/Command F/H 打开查找，Enter 跳至下一项，Escape 关闭；可按当前表、工作簿或打开时的选区查找，选择按行/按列、区分大小写、匹配整个单元格和公式/显示值，支持 *、? 与 ~ 转义。隐藏行命中可临时显示，关闭查找恢复原隐藏状态。替换当前或全部保留字面替换文本；整批数据验证失败时不提交任何更改。按显示值查找时不会覆盖公式，无法对应原始内容的格式化数值也会跳过并报告。每次最多替换 10,000 格，累计生成内容最多 5,000,000 字符。

列宽支持 1–255 个字符输入，采用 `字符 × 7 + 5` 的近似像素换算；默认 112px。输入、自动适配和恢复默认应用到选区覆盖的列，表头双击自动适配单列。拖动列边界在松开时一次提交，Escape 取消；边界可通过键盘左右键、Home/End 调整，Enter 打开设置。跨列合并的内容不参与自动适配；列宽 0 和隐藏列尚未支持。尺寸保留冻结/合并坐标并进入撤销与 XLSX 保存，恢复默认会显式覆盖原文件列宽。

垂直对齐支持顶端、居中和底端。边框提供所有、外侧和无边框，以及六种线型和颜色；合并区域会完整覆盖，保存时保留各边。清空内容与清除格式分开：清除格式保留值、公式、超链接、验证和条件规则，重置字体、普通填充、数字格式、对齐、换行与边框。条件格式仍按规则显示。XLSX 与打印 HTML 包含新对齐、边框和列宽；单边/斜线边框、按格式查找及 Office 精确打印页面设置尚未实现。

## 源码与接入

- UI：`packages/ui/src/components/OfficeStudio/`，公共导出及子路径 `@zui/react/office-studio`。
- 文件适配：`docs/src/pages/collaboration/office-studio/studio-{word,excel,pdf}-codec.ts`。
- PDF 渲染：`studio-pdf-adapter.ts`，负责 PDF.js worker、分页、旋转与点坐标变换。
- 本地存储：`studio-storage.ts` 与 `studio-workspace.ts`。
- 打印：`studio-print.ts`，根据当前模型生成文档内容或导出后的 PDF 打印预览。
- 演示页：`docs/src/pages/components/OfficeStudioPage.tsx`。

```tsx
import { OfficeStudio, type OfficeStudioDocument } from '@zui/react';
import '@zui/react/styles.css';

<OfficeStudio
  value={document}
  source={originalFile}
  pdfRenderer={pdfRenderer}
  height={780}
  onChange={setDocument}
  onSave={async (snapshot: OfficeStudioDocument) => {
    await persist(snapshot);
  }}
  onImport={importFile}
  onExport={exportFile}
  onPrint={printFile}
  onCreate={createFile}
/>;
```

组件管理编辑与反馈，文件解析、持久化、下载及打印由宿主回调实现；示例中的回调名表示应用提供的函数。本仓库提供三种可运行的适配实现。复制到其他业务仓库时，应一起迁移需要的 codec、PDF worker/字体配置、打印和持久化实现，并调整相对导入；CLI 的 `office-studio` 条目复制 UI 组件与其 ZUI 依赖，文档示例中的适配器不属于 UI 包的公共导出。

`ref` 提供 `getDocument()`、`save()`、`export()`、`print()` 和 `setFullscreen(boolean)`。读取模型、保存、导出和打印前会提交当前输入；数据验证失败时保留输入草稿，并阻止读取模型、文件操作和文档切换，修正或取消草稿后可重试。Ctrl/Command S 调用保存；提供 `onPrint` 后 Ctrl/Command P 调用打印。只读模式保留查找、导航、缩放、导出和打印，禁用模式暂停编辑与文件操作。

## 保存与显示

本地示例使用独立 IndexedDB 数据库 `zui-office-studio`，同一记录保存模型、原始 Blob、修订号和保存时间。没有复用旧工作区的 `officeDrafts`。刷新恢复最近文档，文档选择器可打开之前保存的文件。

保存等待事务提交后才确认成功；同一修订号采用事务内比较，两个页面并发保存时拒绝过期写入。保存时继续输入不会覆盖新内容，自动保存随后合并最新版本。新建、导入和切换前排空保存请求。存储失败保留当前编辑数据，仍可导出文件或通过“另存本地副本”生成独立记录。

本地文档空间最多保存 100 份文件，每份保留最近 20 次保存前的历史版本及其原始 Blob。“历史版本”允许只读查看、导出和打印；恢复会创建新文档，当前文件与历史原件继续保留。原数据库升级保留已有文件，失败的事务不写入部分历史记录。历史版本由宿主存储提供，不是 UI 组件自动维护的远端版本服务。

打印以当前模型为准：Word 输出正文、图片、默认页眉页脚及显式分页中的页码；Excel 输出计算值、筛选后的行、合并单元格和图表，并按当前计算结果应用条件格式与数字格式，包括规则着色的空白单元格；PDF 使用包含当前批注和表单值的导出文件。浏览器打印布局与 Office 的自动分页可能不同；Excel 单张打印区域超过 50,000 格时提示改用 XLSX 设置打印区域。实际打印机、浏览器“另存为 PDF”及字体加载需要单独验收。

容器有确定高度，stage 与三种编辑器沿 flex 链设置 `min-height:0` 和 `min-width:0`。页面使用文档站的宽版路由，工具区分组在可用宽度不足时局部水平滚动，画布单独滚动；全屏保留同一编辑实例。保存状态通过 `role="status"` 与 live region 反馈，错误区通过 `role="alert"` 显示消息和重试操作。展开中的文件菜单会随只读、禁用及进行中状态更新，键盘和鼠标都遵守当前可用性。560px 以下标题栏左栏最多 96px，保存状态最多 72px，保留 `aria-live` 和完整 `title`；错误消息允许换行。上述行为已有源码和 jsdom 回归证据，尚无自身页面窄屏视觉结果。

三种编辑内核按需加载，PDF.js 仅在打开 PDF 时载入。组件库公共入口无需提前加载文字编辑和公式计算依赖。

PDF 页面的原始字节仅在文件切换时重新载入。标注/表单变化更新覆盖层，渲染任务支持取消并在卸载和文件切换时销毁 session。坐标使用 PDF 点及左下角原点，经 renderer 映射到当前缩放/旋转的页面。
