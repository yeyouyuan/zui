# 业务区块与页面搭建器 · 2026-11-10

## 业务区块

16 个正式区块按「数据展示」「表单与账户」「系统管理」分组，支持分类与名称搜索组合过滤。桌面使用左侧目录和宽预览，窄屏使用可关闭、可归还焦点的抽屉目录。

预览支持自适应宽度与 390px 手机画布，并可切换组件代码。访问过的区块保留编辑状态；重置仅影响当前区块。个人中心的编辑入口可进入资料编辑页。

同时修复了区块内表格的键盘滚动、选中导航与大屏文字对比度、搜索筛选的按钮语义，以及看板、时间线、选择器和日期控件的可访问名称与角色。

## 页面搭建器

### 从空白到可使用页面

1. 点击「新建页面」，选择空白、产品介绍、联系与收集或项目概览模板。
2. 打开「组件」面板，把组件拖入画布；分区、分栏和表单可容纳其他组件。
3. 点击画布组件，或在「结构」面板展开并选择组件，在属性面板修改内容。支持排序、复制、删除、撤销与重做。
4. 使用桌面、平板、手机画布检查排版；页面设置可修改网页标题、描述、主题、最大宽度和边距。
5. 点击「预览页面」体验实际交互，再下载 HTML，或导出 JSON 继续编辑。

### 组件与交互

共 15 种注册组件，按布局、内容、表单操作分组：

- 布局：内容分区、响应式分栏、分割线。
- 内容：标题、文本、图片、卡片、标签、徽标、进度、提示。
- 表单与操作：表单容器、输入框、开关、按钮。

图片支持 URL 或不超过 1 MB 的 PNG、JPEG、WebP、GIF，本地图片嵌入页面数据。按钮支持链接、页内锚点和提交所在表单。表单支持必填、邮箱等原生校验，并把输入框与命名开关的值生成可下载的 JSON。

独立 HTML 包含样式与固定交互脚本，可直接用浏览器打开；表单校验、开关、清空输入、关闭提示和标签均可使用。外链图片仍需网络。提交数据在当前浏览器处理，下载后由使用方接收或另行对接服务。

### 保存与恢复

- 多页面新建、切换、重命名、复制、确认删除，最多 20 页。
- 编辑后自动保存到当前浏览器，刷新继续；手动保存保留最近 5 个版本，恢复前保留当前内容。
- 支持单页 JSON、原始 Puck Data 和全工作区 JSON 导入；导入追加页面，错误文件保留原草稿。
- 工作区备份包含所有页面与保存版本，导入上限 32 MB；不支持的版本、组件、链接和嵌套表单会给出错误。
- 保存失败保留内存内容，提供重试与下载备份；损坏存档保留原文，确认后才重建。
- 另一标签页更新时暂停自动覆盖，用户可备份本页内容或载入最新存档。
- 编辑中的不完整链接和数值可作为草稿保留；预览和导出进行严格校验。数值渲染限制在有效范围内，避免临时清空字段破坏画布。

保存范围是当前浏览器的本机工作区。跨浏览器、跨设备继续编辑时使用工作区备份；HTML 用于展示与填写，JSON 用于恢复编辑。
