## 使用边界

页面及版本保存于当前浏览器本机。表单生成本地 JSON；未配置后端时不会将数据上传至共享服务。Upload 本地附件属于当前会话，刷新后需重新选择文件；HTTP 上传模式需配置真实服务。内联图片可离线使用，外链图片仍需要网络。

本轮没有修改版本、安装依赖或发布至 GitHub / npm。
