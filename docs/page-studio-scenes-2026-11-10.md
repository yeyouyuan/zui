## 设计操作

- 双击文字，或在快捷栏点击「编辑文字」；支持标题、正文、按钮、标签和卡片标题。Enter 提交，Shift Enter 换行，Esc 取消，失焦保存；输入中的退格和撤销保留文字编辑行为。
- 选中组件后，通过宽 / 高手柄用鼠标调整尺寸，也可用方向键微调；当前设备的覆盖单独保存，调整结束记录一次撤销历史。
- 容器、分区、分栏、卡片和应用内容视图支持纵向、横向、两列、三列和主侧栏快捷布局。卡片标题与分区标题保持独立，布局作用于内容槽。
- 可包裹为容器、解散容器、选择父级；保留原有全部 ZUI 组件、嵌套、图层锁定与隐藏、样式细调、自定义 CSS、图片、撤销重做和多页版本能力。
- 页面设置提供六套配色与全局圆角；自定义主色可继续覆盖预设。
- 「我的区块」保存选中节点及全部子节点、三端样式与依赖数据；跨页插入时重新生成节点 ID，目标数据源发生同名异值冲突时重命名并重写绑定。
- 区块库可独立导入 / 导出；插入区块生成独立副本，不包含主组件更新后自动同步全部实例或组件变体系统。

## 页面数据

左侧「数据」面板支持新建空数据源或示例数据源，配置显示名、字段名、字段类型、必填和选项。表格编辑与 JSON 编辑均需点击「应用数据源」才生效。

- 字段类型：文本、数值、邮箱、日期、选项。CSV / JSON 导入上限 4 MB；支持带引号的逗号、多行和双引号转义；非数字值不能应用到数值字段。
- 每页最多 12 个源，每源 1–20 个字段、1000 行。每个节点通过数据源和字段选择绑定。
- 数据管理表格：搜索、单字段筛选、列排序、分页、详情、新建、编辑、勾选批删和导出筛选后的 CSV。
- 统计卡：计数、求和、平均与等值筛选。图表：按字段分组的计数 / 求和，柱状、折线、环形图，可切换为数据表；SVG 提供数据辅助名称。
- 内容集合：卡片 / 列表、最大列数、搜索、详情。录入表单按源字段生成，并执行浏览器输入校验。
- REST 源配置 HTTP / HTTPS GET 地址及结果路径（如 `data.items`）。可测试并保存设计样本；画布与模板缩略图使用样本，运行时请求真实数据，显示加载、空结果、错误与重试。

## 保存与使用边界

编辑器页面继续保存在当前浏览器本机。新建与复制页面生成独立运行数据标识；单页 JSON 导入保留导出的标识，避免备份往返意外改变数据身份。

本地源的运行数据在可访问 localStorage 的独立页面中持久保存；键包含页面标识、源 ID 与字段 / 初始数据指纹。重新配置源或初始数据会建立新的运行数据版本。沙箱交互预览无法持久存储时，会明确提示数据仅在当前会话有效，可以用 CSV 导出备份。

编辑器工作区 JSON 保存页面设计和源样本，不自动包含独立页面中后续增删改的运行记录；运行记录请另外导出 CSV。「我的区块」另存本机，需使用区块库导出做备份。

REST 当前只读，不发送凭据或保存服务端密钥，接口需允许浏览器跨域。多人共享、账号权限、服务端写入、数据库、跨设备同步和托管发布仍需要后端服务，本轮没有实现这些能力。浏览器保存不会使数据成为多人共享数据库。

HTML 导出继续内联 React / ZUI 和组件样式；本地源模板离线可用，REST 源及外链媒体需要网络。

- 原有分区排版测试增加对 Puck 内容槽异步挂载的等待，没有跳过布局断言；修复数量文字对比度不足与导入数据标识变化。
