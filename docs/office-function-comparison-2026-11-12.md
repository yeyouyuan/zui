# OfficeStudio 功能细节对照（2026-11-12）

2026-11-13 已扩展为五个主要仓库的全量源码扫描与逐项台账，见 [源码梳理](onlyoffice-source-review-2026-11-13.md) 和 [196 项功能台账](onlyoffice-feature-ledger-2026-11-13.md)。这里仍记录原有实现范围，不能作为全部功能对齐证明。

本表按实际操作核对自研 OfficeStudio。参照 ONLYOFFICE 的工具分组、编辑命令与文件行为，不能据此宣称已与 Microsoft Office 完全兼容。“已实现”仅指右列描述的范围；“部分”说明入口或基础能力存在，但关键场景仍有差距。Word、Excel、PDF 均继续使用 ZUI 控件。

本轮重点补齐 Excel 查找替换、列宽、垂直对齐、边框和清除格式，覆盖选区、快捷键、撤销、数据验证与文件保存。其他项目按当前源码登记，未把未实现的功能算入完成项。

## 下一轮优先顺序与验收方式

1. 常用编辑继续补齐：Word 字号步进/高亮/大小写/格式刷；Excel 独立显示隐藏行列、Ctrl + 方向键、可拖动填充柄及跳过空格/运算粘贴。
2. 完成表格和页面：Word 表格边框/标题行、分节/页眉页脚差异；Excel 多关键字排序、组合筛选、打印范围和分页预览。
3. 再评估独立内核能力：结构化表/透视、Word 修订/目录域/脚注、PDF 页面组织与原文编辑；不得以占位按钮宣称已实现。

每项验收至少包含：操作前后结果、选区与焦点、撤销重做、只读/禁用、文件保存重开、失败时原数据保留。页面与实际打印需分别验收。当前测试入口为 `StudioSheet.test.tsx`、`StudioSheetSearch.test.tsx`、`studio-sheet-editing.test.ts`、`docs/tests/studio-excel.test.mjs`、`docs/tests/studio-print.test.mjs`；详细结果见[验收记录](office-verification-2026-11-12.md)。
