# RFC-007：组件创意工坊

状态：2026-11-09，10 个可交互设计原型已实现于文档站 `#/lab`。本 RFC 记录设计探索与正式化边界，尚未新增 `@zui/react` 包导出或 Registry 条目。

## 目的与视觉方向

让功能复杂的界面仍然清楚、克制、有层次。目录按数据洞察、文件协作、团队效率、创作配置组织；每个设计包含说明、可操作画布与能力标签。主色使用语义成功色，辅以暖色状态、细边框与明确留白；全部跟随文档明暗主题。小屏下画布纵向排列，交互信息完整保留。

首页探索区、侧栏导航与命令面板均能发现工坊。目录组合分类与关键词过滤，隐藏设计保留挂载，从而保留任务、筛选与草稿状态。离开路由或刷新页面会重置演示数据。

## 实现边界

- 原型代码位于 `docs/src/pages/lab/`，按领域分为四个文件，共用 `LabCard`、`Choices`、`Notice` 和头像展示。
- 表单使用原生 input/select/textarea/checkbox，按钮切换使用 `aria-pressed`；不引入需要额外键盘模型的伪 tabs/grid。
- 文件弹窗复用正式 `Modal` 的焦点约束、Escape 与焦点恢复，动作按钮复用 `Button`。
- 指标与文件均为站内固定样例；归档、任务、审批和预约只改变页面内存。添加成员仅用于本页演示，不发送邀请。
- 预约固定为 2026-11-09 至 2026-11-13、Asia/Shanghai；不可预约时段不可提交，已有预约取消后才能选择下一次预约。
- 版本对比使用预先对应的五行样例，不宣称实现通用 diff 算法。
- 权限矩阵用于演示角色与能力关系；真实权限必须由服务端验证。
- 本次不变更包版本、正式组件数量或 npm 发布状态。

## 验收

自动化见 `e2e/ui-lab.spec.ts`：目录筛选与状态保留、条件组合执行、文件筛选/归档/预览/焦点恢复、版本定位、任务流转焦点、审批校验与历史、通知状态、权限矩阵、预约状态、样式实际计算值，以及 1440px/320px × 浅色/暗色完整 axe 与溢出检查。全站逐页审计自动纳入该路由。

浏览器自动化与截图不能代替 VoiceOver/NVDA、真实触摸和跨系统原生选择控件人工验证。进入正式实现前，每个候选至少验证两个消费场景，再决定是独立组件、既有组件扩展还是业务块。
