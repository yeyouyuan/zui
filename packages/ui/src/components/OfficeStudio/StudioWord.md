# Word 编辑器

`StudioWord` 是 `OfficeStudio` 按需加载的 Word 内核，工具栏、字体选择、颜色、图片尺寸、查找、大纲和页眉页脚设置使用 ZUI 控件。编辑结构采用 Tiptap / ProseMirror，文件编码由宿主完成。

支持正文、标题、字体字号、颜色和文字背景、粗体斜体下划线删除线、上下标、对齐、段落缩进间距、嵌套列表、表格及行列合并拆分、链接、水平线、显式分页、纸张方向与缩放。正文和默认页眉页脚各自保留编辑历史；受控更新被宿主拒绝时，画布恢复到宿主接受的模型。

本地 PNG / JPEG 可通过文件选择或粘贴插入正文、页眉或页脚。点击图片进入图片工具，可设置宽高、锁定比例、修改替代文字、删除和撤销。单图最大 8 MiB，文件适配器限制全部嵌入图片为 25 MiB。不读取远程图片地址。

`header`、`footer` 是可选 `doc` 根节点。插入栏可以创建或聚焦默认页眉页脚，工具栏格式作用于当前区域。`page.headerDistance` / `footerDistance` 以 mm 表示，支持 0–80。`pageNumber` 行内节点的 `attrs.kind` 为 `current` 或 `total`，导出为原生 PAGE / NUMPAGES 域；画布显示字段占位值，页码由打开 DOCX 的排版程序计算。勾选“显示页码”会向已有页脚添加默认页码。

Ctrl / Command F 或 H 打开当前区域的查找与替换。匹配可以跨文字样式，支持大小写、Enter / Shift Enter 导航、单项与全部替换。替换使用纯文本和一个撤销事务。超过 10,000 处匹配时禁用全部替换并提示缩小查询范围；替换后的文本限制为 200 万字符。大纲列出正文标题并支持跳转。只读状态保留查找、标题导航、缩放和选择，关闭修改入口。

示例 DOCX 适配器位于 `docs/src/pages/collaboration/office-studio/studio-word-codec.ts`，支持内嵌 PNG / JPEG、单节默认页眉页脚、阿拉伯 PAGE / NUMPAGES 域和普通文字、列表、表格的真实文件往返。浮动图、图形效果、裁剪、旋转、SVG、外链图片、修订、目录、不同首页、奇偶页、多节、复杂编号及未知域会明确拒绝，避免导出丢失对象。

画布使用连续纸张与显式分页。它没有 Office 的完整自动分页、字体度量和复杂版式兼容能力；页眉页脚画布预览显示在连续文稿的顶部和底部。DOCX 的纸张和页眉页脚距离供打开文件的排版程序使用。

验证入口：`StudioWord.test.tsx` 和 `docs/tests/office-studio-word.test.mjs`。测试覆盖实际编辑、只读、受控回退、图片缩放删除撤销、页眉格式、查找替换，以及真实 ZIP 内嵌图片、页眉页脚和页码域重复导出重开。
